# Deborara Website

A personal website for Debora, built with React and Next.js. The experience should feel like an interactive documentary of her life, work, personality, and ambitions—not a conventional portfolio.

## Technical Direction

- Next.js
- React
- Responsive design
- Light and dark modes
- Language support
- Motion and scrollytelling
- Accessible, keyboard-friendly interactions
- Subtle animation by default, with reduced-motion support

## Experience Ideas

- Use scrollytelling throughout the site.
- Present Debora’s talents as a “choose your character” interaction.
- Potential talent categories: Learner, Problem Solver, Communicator, and one additional category.
- Include hand-drawn arrows, handwritten details, and playful annotations.
- Animate the profile image or transition between several portraits.
- Create a “How well do you know Debora?” game using personal facts.
- Make “Get in touch” a memorable interaction, with a pre-populated email action.
- Support English first, with French and Dutch structured as future additions.
- Include a polished light/dark theme toggle.

## Proposed Pages

- **About** — Debora’s personal story
- **Work** — career, extracurriculars, and projects
- **Now** — what she is currently focused on
- **Testimonials** — recommendations and stories from collaborators
- **Articles** — a connection to her Substack/blog
- **How Well Do You Know Debora?** — interactive game replacing a traditional FAQ
- **Working With Me** — hidden, shareable page describing communication and working style
